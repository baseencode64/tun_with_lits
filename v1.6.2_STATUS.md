### Issue #1: `vpn_server_ip` not updating after reconnect

```
❌ Before: IP remains stale after failover
✅ After: IP updates immediately on new connection
```

**Implementation**:

- All related metrics updated: `vpn_server_ip`, `vpn_tun_ipv4`, `vpn_tun_ipv6`

**Code Location**: [pkg/client/client.go](pkg/client/client.go#L470-L480)

---

### Issue #2: Byte metrics reset on reconnection

```
❌ Before: vpn_bytes_read_total and vpn_bytes_written_total = 0 after failover
✅ After: Metrics accumulate all traffic across reconnections
```

**Implementation**:

1. Added cumulative byte counters to Client struct
2. Modified `Disconnect()` to preserve bytes before tunnel closes
3. Updated metrics calculation to sum: cumulative + current

**Code Locations**:

- Cumulative fields: [pkg/client/client.go](pkg/client/client.go#L280-L285)
- Disconnect preservation: [pkg/client/client.go](pkg/client/client.go#L530-L545)
- Metrics calculation: [pkg/client/client.go](pkg/client/client.go#L1050-L1060)

## 💬 Technical Notes

### Atomic Operations

All cumulative counters use Go's `atomic` package:

- `atomic.AddInt64()` for incrementing
- `atomic.LoadInt64()` for reading

This ensures thread-safety without explicit locks.

### Backward Compatibility

- No configuration file changes needed
- No command-line flag changes
- Existing deployments can upgrade directly

### Performance Impact

- Minimal: Only 2 additional atomic operations per disconnect
- Negligible: No blocking operations added
- Scalable: Works with any number of reconnections

## 📞 Support & Troubleshooting

### Verify Metrics Working

```bash
# Check metrics endpoint
curl http://localhost:9090/metrics 2>&1 | wc -l

# Should show hundreds of metrics ✅

# Monitor specific metrics
watch -n 1 'curl -s http://localhost:9090/metrics | grep -E "vpn_bytes|vpn_server"'
```

### Debug Logging

```bash
# View detailed logs
sudo journalctl -u goxray -f | grep -E "Metrics state|VPN server IP|Bytes preserved"

# Should show:
# - "Metrics state on reconnection"
# - "VPN server IP metric updated"
# - "Bytes preserved on disconnect"
```

### Common Issues

- **Metrics not updating**: Check that client was restarted with v1.6.2
- **Old IP still showing**: Clear prometheus cache or wait 5 minutes for cache expiry
- **Bytes reset to 0**: Likely running old version; upgrade to v1.6.2
